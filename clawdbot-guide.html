📋 LLM TASK

Status: ✅ Loaded | ✅ Configured

What: JSON-only LLM tool with schema validation

Returns: Structured JSON with validation against schema

Configuration

{
  "plugins": {
    "entries": {
      "llm-task": { "enabled": true }
    }
  },
  "agents": {
    "list": [{
      "id": "main",
      "tools": { "allow": ["llm-task"] }
    }]
  }
}

ParameterTypeDescription
promptstringTask instruction (required)
inputanyData to process
schemaobjectJSON Schema for validation
providerstringModel provider
modelstringModel ID
temperaturenumber0-1 (default 0)

📋 LLM TASK - DEEP DIVE

✅ What is LLM Task?

A JSON-only LLM tool that returns structured data with optional JSON Schema validation. Perfect for when you need machine-readable output, not natural language.

🎯 Key Features

  • ✅ Returns ONLY JSON (no commentary)
  • ✅ Optional schema validation
  • ✅ No tools exposed to model
  • ✅ Deterministic output
  • ✅ Integrates with Lobster workflows
  • ✅ Configurable model & provider

🔗 Integration with Lobster

The llm-task tool works seamlessly with Lobster workflows:

{
  "name": "email-processing-pipeline",
  "steps": [
    {
      "id": "classify",
      "task": "llm_task",
      "input": { "emails": "$emails" },
      "config": {
        "prompt": "Classify each email",
        "schema": { /* classification schema */ }
      }
    },
    {
      "id": "route",
      "task": "llm_task",
      "input": { "classified": "$classify.result" },
      "config": {
        "prompt": "Route tickets to appropriate teams",
        "schema": { /* routing schema */ }
      }
    },
    {
      "id": "notify",
      "task": "approve",
      "dependsOn": ["route"],
      "input": { "routing_decisions": "$route.result" }
    }
  ]
}
