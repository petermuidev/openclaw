PLUGIN 3: LLM TASK
------------------
Description: JSON-only LLM tool for structured tasks with schema validation

STATUS: ✅ Loaded (needs agent allowlist)

WHAT IT DOES:
- Runs LLM tasks returning only JSON
- Validates output against JSON Schema
- No tools exposed to model
- Integrates with workflow engines

CONFIGURATION:
Add to ~/.clawdbot/clawdbot.json:
{
  "agents": {
    "list": [{
      "id": "main",
      "tools": { "allow": ["llm-task"] }
    }]
  }
}

HOW TO USE:
-----------
# Via agent (when allowed)
clawdbot agent --message "Classify this email sentiment and category" --deliver

# Direct API (when configured)
{
  "prompt": "Classify this email",
  "input": { "email": "Hello, I want to cancel my subscription..." },
  "schema": {
    "type": "object",
    "properties": {
      "sentiment": { "type": "string", "enum": ["positive", "negative", "neutral"] },
      "category": { "type": "string" },
      "priority": { "type": "string", "enum": ["low", "medium", "high"] }
    }
  },
  "model": "gpt-5.2"
}

USE CASES:

PLUGIN 4: LOBSTER

Description: Workflow runtime - deterministic pipelines with approval gates

STATUS: ✅ Loaded (needs agent allowlist + CLI)

WHAT IT DOES:
- Typed JSON workflow pipelines
- Human approval checkpoints
- Resume from checkpoints
- Integration with Clawdbot tools

INSTALLATION:
npm install -g @clawdbot/lobster
# Note: Windows/Node 22 has ESM issues - may need Node 20

CONFIGURATION:
Add to ~/.clawdbot/clawdbot.json:
{
  "agents": {
    "list": [{
      "id": "main",
      "tools": { "allow": ["lobster"] }
    }]
  }
}

HOW TO USE:
-----------
# Create workflow file (workflow.json):
{
  "name": "content-pipeline",
  "steps": [
    {
      "id": "research",
      "task": "web_search",
      "input": "AI trends 2026"
    },
    {
      "id": "draft",
      "task": "llm_task",
      "input": "Write draft based on research",
      "dependsOn": ["research"]
    },
    {
      "id": "review",
      "task": "approve",
      "dependsOn": ["draft"]
    },
    {
      "id": "publish",
      "task": "post_to_blog",
      "dependsOn": ["review"]
    }
  ]
}

# Run workflow (when CLI works)
lobster run workflow.json

USE CASES:
----------
✓ Multi-step automation
✓ Content creation pipelines
✓ Approval workflows
✓ Data processing chains
✓ Deployment pipelines

EXAMPLE WORKFLOW:

# Daily news digest
